# .github

Organisation-wide files for [InfraNest](https://infranest.app) — *domains, DNS, cloud servers,
certificates and uptime monitoring, in one place, across every provider.*

| File | What it is |
|---|---|
| [profile/README.md](profile/README.md) | The organisation profile page — what GitHub renders at [our org front page](https://github.com/InfraNest-Infrastructure-Organized) |
| [SECURITY.md](SECURITY.md) | How to report a vulnerability, and what happens next |
| [SUPPORT.md](SUPPORT.md) | Where to go for product help, which is not GitHub |

GitHub applies the community health files here as the **default for every repository in the organisation**
that does not define its own, so a new repository inherits the security policy and the support pointer
without anyone remembering to copy them.

Nothing in this repository is secret; it is public by design.
