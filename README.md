# .github

Organisation-wide files for [InfraNest](https://infranest.app).

- **[profile/README.md](profile/README.md)** — the text GitHub renders on the organisation profile page.

Community health files placed here (`SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, issue and pull
request templates) apply as the default to every repository in the organisation that does not define its
own.
